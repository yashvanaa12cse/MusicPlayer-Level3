# Music Player

A simple Android Music Player app created for the Android Development Recruitment Task.

## Level Completed
Level 1 - UI & Navigation

## Features
- Home screen with 5 hardcoded songs
- Song thumbnail, title and artist
- Clickable song list
- Now Playing screen
- Play/Pause visual interaction
- Back navigation
- Toast feedback

## Technology
- Java
- XML
- Android SDK
- AndroidX AppCompat
- Material Components

## Note
Level 1 does not require actual audio playback.
